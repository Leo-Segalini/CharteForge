PostgreSQL local + Drizzle

v0.1.0 Mis à jour le 18 novembre 2026 Stable

Description

CharteForge stocke users, brands et assets dans PostgreSQL via Drizzle. En local, un conteneur Docker expose Postgres sur le port 5434 pour ne pas entrer en conflit avec une instance système sur 5432.

Démarrage rapide

  1. Copier .env.example → .env (variables SQL_*)
  2. npm run db:up — démarre charteforge-postgres
  3. npm run db:push — crée les tables depuis src/db/schema.ts
  4. npm run dev — serveur Express + Vite

Variables d’environnement

VariableValeur localeRôle
SQL_HOST127.0.0.1Hôte Postgres
SQL_PORT5434Port hôte Docker
SQL_USER / SQL_PASSWORDcharteforgeConnexion app
SQL_DB_NAMEcharteforgeBase
SQL_ADMIN_*identiquedrizzle-kit push

Sans SQL_DB_NAME, le driver pg utilise le nom d’utilisateur OS comme base (ex. segalini-briant) → erreur « database does not exist ».

Sécurité

  • Mots de passe locaux uniquement dans .env (gitignoré)
  • Port non standard 5434 — pas d’exposition publique en local
  • Pas de secrets dans la doc ni dans docker-compose.yml (dev only)
