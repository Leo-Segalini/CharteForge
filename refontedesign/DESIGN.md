## Brand & Style

This design system embodies the calculated elegance of high-tier developer tooling and professional design software. It is crafted for digital product creators, brand designers, agency leads, and design engineers who demand mathematical rigor, typographic perfection, and institutional clarity.

The aesthetic fuses **Precision Engineering** with **Modern Craft Minimalist** disciplines. It avoids unnecessary ornament, relying instead on razor-thin hairline borders, disciplined negative space, subtle luminous elevation, and pristine data hierarchy. Visual tension is achieved by pairing deep slate blues and authoritative dark navy surfaces against crisp slate-white backgrounds, energized by an amber ochre accent that communicates studio warmth and creative craft. Every element exists with intent: high information density, absolute legibility, and effortless utility.

## Colors

The palette is engineered around strict contrast ratios and disciplined roles:

- **Primary (`#182B49`)**: Deep Navy serves as the anchor for primary interaction surfaces, high-priority buttons, key brand badges, and dominant dark panels.
- **Secondary (`#C97B36`)**: Warm Ochre / Terracotta Amber acts as the precise editorial highlight for metric badges, section prefixes, dynamic active states, and focal accents.
- **Tertiary (`#0F172A`)**: Slate 900 provides definitive contrast for primary headlines, terminal code wrappers, and high-impact structural blocks.
- **Surfaces**: Pure `#FFFFFF` anchors elevated cards and inputs, set against canvas layers of `#F8FAFC` and `#F1F5F9`.
- **Status & WCAG Semantics**:
  - `wcag-pass` (`#059669` with `#ECFDF5` fill): Confirms strict AA / AAA accessibility validation.
  - `wcag-warning` (`#D97706` with `#FFFBEB` fill): Flags partial compliance or large-text-only thresholds.
  - `wcag-fail` (`#E11D48` with `#FFF1F2` fill): Flags non-compliant pairings or critical system alerts.

## Typography

The typographic hierarchy implements an editorial split:

- **Headlines & Interface Text**: Executed in **Plus Jakarta Sans**, offering geometric clarity with subtle warmth. Headlines feature negative letter-spacing (`-0.02em` to `-0.03em`) to deliver authoritative weight without harshness.
- **Eyebrows & Technical Tokens**: Uppercase section tags (`label-eyebrow`) utilize **JetBrains Mono** with loose tracking (`+0.08em`) rendered in the warm ochre tone, creating an unmistakable architectural feel.
- **Data, Code & Color Readouts**: Hex strings, contrast calculations (`14.1 : 1`), and CSS variables are strictly set in **JetBrains Mono** to reinforce deterministic accuracy.

## Layout & Spacing

The layout model runs on a 12-column responsive fluid grid bounded at a maximum width of `1280px` for balanced reading:

- **Desktop (>= 1024px)**: 12-column grid with `1.5rem` (`24px`) gutters and `2rem` (`32px`) margins. Section rhythm flows at `4.5rem` (`72px`) intervals to maintain deliberate breathing room between discrete feature blocks.
- **Tablet (768px - 1023px)**: 8-column layout with `1.25rem` (`20px`) gutters and `1.5rem` (`24px`) margins. Multi-column cards wrap into 2-column matrices.
- **Mobile (< 768px)**: 4-column layout with `1rem` (`16px`) gutters and margins. Side-by-side metric tables stack vertically into dedicated micro-cards.
- **Component Density**: Internal element groupings utilize a tight 4px/8px rhythm (`space-xs` through `space-md`), balancing spacious layouts with compact, tool-like component density.

## Elevation & Depth

This system avoids blurred, heavy dropshadows in favor of razor-sharp surface separation, micro-elevation, and sub-pixel edge definition:

- **Surface Grounding**: Base canvas sits on `#FFFFFF` or `#F8FAFC`. Floating elements (cards, table rows, popovers) utilize solid `#FFFFFF` backed by a 1px border of `#E2E8F0` at 80% opacity.
- **Micro-Elevation**: Hoverable cards utilize a diffuse shadow formula: `0 1px 2px 0 rgba(15, 23, 42, 0.04), 0 4px 12px 0 rgba(15, 23, 42, 0.03)`.
- **Active & Floating Overlays**: Modals and elevated flyouts apply `0 12px 32px -4px rgba(15, 23, 42, 0.08), 0 4px 8px -2px rgba(15, 23, 42, 0.04)` combined with a crisp perimeter border.
- **Dark Terminal Blocks**: Monolithic dark surfaces (`#0F172A`) use an inset highlight hairline `inset 0 1px 0 0 rgba(255, 255, 255, 0.08)` and outer edge `1px solid #1E293B`, producing crisp depth against light canvas backgrounds.

## Shapes

The geometry balances technical crispness with modern software ergonomics:

- **Containers & Cards (`rounded-lg`, 0.75rem / 12px to 1rem / 16px)**: Exterior card frames and code preview shells employ balanced corners that soften interface density while maintaining structured alignment.
- **Controls & Form Elements (`rounded`, 0.5rem / 8px)**: Standard buttons, text fields, search bars, and dropdown triggers utilize an 8px radius for optimal hit targets.
- **Pill Badges & Chips (`rounded-full`, 9999px)**: WCAG conformance badges, tag metrics, and color chip pills feature a continuous round profile, providing distinct visual separation from structural rectangular cards.

## Components

### Buttons
- **Primary**: Solid Deep Navy (`#182B49`), text `#FFFFFF`, 8px radius, height 40px (desktop) / 44px (touch). Padding 0 18px. Sub-pixel top border highlight `inset 0 1px 0 rgba(255,255,255,0.15)`. Hover: `#0F172A` with subtle scale transition.
- **Secondary / Outline**: Background `#FFFFFF`, 1px border `#E2E8F0`, text `#0F172A`. Hover: background `#F8FAFC`, border `#CBD5E1`.
- **Accent**: Background Warm Ochre (`#C97B36`), text `#FFFFFF`. Reserved strictly for primary export CTAs or high-conversion triggers.
- **Tertiary / Ghost**: Transparent fill, text `#475569`. Hover: background `#F1F5F9`, text `#0F172A`.

### Status & Accessibility Badges
- Pill-shaped tags (`font-family: JetBrains Mono`, 11px font weight 600, uppercase).
- **Conforme (Pass)**: Background `#ECFDF5`, text `#059669`, border `1px solid #A7F3D0`. Includes a 6px solid emerald dot before text.
- **Warning (Grands Titres / Large Text)**: Background `#FFFBEB`, text `#D97706`, border `1px solid #FDE68A`.
- **Non Recommandé (Fail)**: Background `#FFF1F2`, text `#E11D48`, border `1px solid #FECDD3`.

### Interactive Data Cards
- Container: Background `#FFFFFF`, border `1px solid #E2E8F0`, 12px radius, padding 24px.
- Subtle top badge indicator featuring mono numeric sequences (`01`, `02`, `03`) in `#C97B36`.
- Card Title: 18px weight 600, color `#0F172A`. Description: 14px weight 400, color `#475569`, leading 22px.
- Hover state: Border shifts to `#CBD5E1` with a `translateY(-2px)` ease curve.

### Code & Token Specimen Blocks
- Container: Solid Dark Slate `#0F172A`, 12px radius, border `1px solid #1E293B`, padding 20px.
- Text: Full mono syntax highlighting via `#94A3B8` (keys), `#38BDF8` (attributes), and `#C97B36` (color token strings).
- Floating copy button: `#1E293B` background with `#F8FAFC` icon on top-right anchor.

### Form Inputs & Text Fields
- Base height 40px, 8px radius, border `1px solid #E2E8F0`, background `#FFFFFF`.
- Typography: 14px `#0F172A`, placeholder `#94A3B8`.
- Focus state: Border `#182B49`, box-shadow `0 0 0 3px rgba(24, 43, 73, 0.12)`.

### Color Swatch Tiles
- Dual-zone component: Upper half displays the raw hex fill with an inset ratio tag. Lower half displays technical data: Hex `#182B49`, CMYK, and WCAG contrast rating in JetBrains Mono.
- Border radius: 8px outer shell with 1px hairline border `#E2E8F0`.
